# Platform B.A. — AI Business Advisory & Audit Platform 📊🤖

Интеллектуальная платформа для глубокого управленческого, финансового и операционного аудита бизнеса на основе анализа разнородных источников данных и моделей Google Gemini.

---

## 🌟 Ключевые возможности

- **Мультиформатный парсинг данных**:
  - **Таблицы**: Excel (`.xlsx`, `.xls`), CSV
  - **Документы**: PDF (через специализированный парсер на PyMuPDF), Word (`.docx`)
  - **Архивы**: ZIP, RAR, 7z (автоматическая распаковка и анализ структуры)
  - **Веб-источники**: Прямой импорт Google Sheets, веб-страницы и HTML-отчеты
  - **Изображения & Чеки**: Распознавание текста и кассовых чеков с помощью OCR (Tesseract.js)
- **Grounded AI Audit (Аудит с пруфами)**:
  - Каждая метрика, факт и вывод строго привязаны к конкретному источнику (строка таблицы, абзац документа, чек).
  - Выявление "узких мест" (Bottlenecks) с градацией критичности: Critical, Warning, Info.
  - Пошаговые рекомендации действий (P1 Urgent, P2 Medium, P3 Strategic) с расчетом ожидаемого эффекта.
- **Интерактивная панель доказательств (Evidence Drawer)**:
  - Возможность кликнуть по любому выводу аудитора и моментально увидеть первоисточник данных.
- **Интерактивный AI Чат по кейсу**:
  - Задавайте вопросы по загруженным данным и отчету в режиме реального времени.
- **Экспорт в NotebookLM & Отчетность**:
  - Генерация структурированных брифов для загрузки в Google NotebookLM (генерация подкастов, конспектов, FAQ).

---

## 🛠 Технологический стек

- **Frontend & Backend**: [Next.js 15](https://nextjs.org/) (App Router), React 19, TypeScript
- **Стилизация & UI**: Современный стек с адаптивным темным/светлым интерфейсом, Lucide React
- **Парсинг & Инженерия данных**:
  - `xlsx`, `papaparse` — табличные данные
  - `jszip` — распаковка архивов
  - `tesseract.js` — локальное оптическое распознавание символов (OCR)
  - Python-хелперы (`pymupdf`, `python-docx`) для сложной обработки PDF и документов
- **AI Модели**: Google Gemini API (`gemini-2.5-flash`, `gemini-3-flash-preview` и др.)

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/CrystaLLCoding/PLATFORM_B_A.git
cd PLATFORM_B_A
```

### 2. Установка зависимостей Node.js
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env.local` в корне проекта (на основе `.env.example`):
```env
# Ваш ключ Google Gemini API
GEMINI_API_KEY=your_actual_gemini_api_key

# Модели Gemini с fallback (по приоритету)
GEMINI_MODEL=gemini-2.5-flash,gemini-3-flash-preview,gemini-3.5-flash,gemini-3.1-flash-lite
```

### 4. (Опционально) Зависимости Python
Для расширенного парсинга сложных PDF и docx файлов рекомендуется наличие Python 3:
```bash
pip install pymupdf python-docx
```

### 5. Запуск сервера разработки
```bash
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3005](http://localhost:3005) (или порт, указанный в package.json).
